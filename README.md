# Aura Agents (AURA)

8,000 Agent ID-gated NFTs on BNB Smart Chain — 16 auras, each with its own art.

- **Supply:** 8,000 total — 7,200 free (Agent ID holders only), 800 paid at $0.35
- **Mint:** 2 free per wallet, up to 10 per wallet
- **Contract:** `0xacc6e2F1aaE42B2E5FF2758Ff078E4B1bfAc7DB1` (BSC mainnet, verified on BscScan)
- **Royalties:** 5%
- **Live site:** https://aura-agents.pages.dev/

## How it works

Only Binance Agent ID holders can mint. Free mints are 2 per wallet; paid mints are $0.35 each. Each token shows one of 16 auras.

No floor price, returns, or token promises — just the collection and the live site.
