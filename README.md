# Aura Agents (AURA)

Aura Agents is a collection of 8,000 NFTs on BSC mainnet, in 16 auras with art of their own. Minting is gated by Binance Agent ID.

Contract: [0xacc6e2F1aaE42B2E5FF2758Ff078E4B1bfAc7DB1](https://bscscan.com/address/0xacc6e2F1aaE42B2E5FF2758Ff078E4B1bfAc7DB1)

Supply: 8,000 total. 7,200 free and 800 paid. Free minting is 2 per wallet, with a max of 10 per wallet, and it is still open. Paid minting costs 0.0005 BNB ($0.35) per mint.

Minted: 5,577 as of 15 Nov 2026, including 3 paid mints. See the live count on BscScan: https://bscscan.com/token/0xacc6e2F1aaE42B2E5FF2758Ff078E4B1bfAc7DB1

Site: https://aura-agents.pages.dev/

Royalties: 5%.

No floor price, no returns, and no token promised.

One of 13 Agent ID NFT collections the same builder shipped on BSC mainnet.
